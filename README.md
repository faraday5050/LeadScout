# 🎯 LeadScout - Smart Lead Prioritization

> **AI-powered lead prioritization for bank telemarketing campaigns.**

LeadScout predicts which clients are most likely to subscribe to a term deposit, enabling marketing teams to focus on high-potential leads and improve ROI.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔮 **Real-Time Prediction** | Predicts client subscription with 81.2% accuracy |
| 📊 **Intelligent Dashboard** | Real-time analytics, conversion tracking, performance metrics |
| 🤖 **AI Lead Assistant** | Natural language chat with Groq AI for lead insights |
| 📁 **Bulk Processing** | CSV upload for batch predictions (up to 1000 leads) |
| 👤 **Lead Management** | Search, filter, delete, and export leads |
| 📈 **Analytics & Insights** | Top predictors, job distribution, monthly trends |
| 🎯 **Lead Scoring** | 7-factor scoring with actionable insights |
| 📱 **Mobile Responsive** | Works on all devices |
